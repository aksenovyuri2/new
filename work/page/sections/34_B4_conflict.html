Схема Б4★ ядроВопрос 1.3 · конкуренция вертикалей и маркетинга

В первой версии спор решают классы и нижние планки; потолки — только после доказанного вреда

Тип сообщению присваивает платформа, а не заказчик: иначе промо начнут выдавать за заказанное, чтобы обойти лимит. Спорят только промо: у каждой вертикали есть нижняя планка, над ней общий лимит и очередь. Во второй версии места внутри лимита делит единая оценка по модели ценности (Ц1, Ц2), а не ручные доли: с третьего квартала в режиме тени, решения — после сверки заменителя. Для аренды и вторички ручные доли остаются, пока не измерена доля выручки размещения k.

Ответ на вопрос кейса

  • Сначала классы: сервисное и подписки не спорят с промо. Класс присваивает платформа, а не заказчик.
  • Спорят только промо. У каждой вертикали нижняя планка — её доля в промо квартала, не ниже текущей, {{b1_floor_quarters|num0}} квартала. Это доля, а не число сообщений: при общем сокращении режутся все пропорционально. Над планками общий лимит, внутри него очередь по классу и свежести; события с малым сроком идут по быстрой полосе.
  • Потолков в первой версии нет. Их вводим только после доказанного вреда: сначала замер, потом решение совета.
  • Лазейку «подписки» закрываем: автоподписка живёт в классе Б испытательный срок, без реакции человека переходит в промо. Одинаковые события за сутки склеиваются: по общему поводу вроде смены ставки человеку уходит одно сообщение, а не по одному от каждой вертикали.
  • Рост объёма сверх лимита — только решением CPO, с датой окончания и записью в журнал.
  • Вторая версия — оценка по модели ценности (Ц1, Ц2) вместо ручных долей. Внутри лимита место получает кандидат с большей ценностью: выручка сейчас + прирост выручки человека против следующего лучшего кандидата − цена канала. По одной формуле оцениваются промо вертикалей, своё сообщение и реклама. Сроки: модели прироста — второй квартал, оценка в тени — третий, решения — после сверки заменителя, не раньше {{p2_dec_from|num0}}–{{p2_dec_to|num0}}-го месяца. Правила утверждает совет по вниманию раз в квартал. Нижняя планка остаётся долей. Аренда и вторичка: пока k не измерено, места делят ручные доли текущего плана, а не Δ; доля рекламы в слоте не ниже текущей.
  • Планка и сокращение отправок не спорят. Сокращение на 10–20% идёт в хвосте людей с 3+ промо в сутки и в сегментах с доказанно нулевым эффектом; доли вертикалей не меняются. Сумму планок сверяем с лимитом по карте точек отправки к 3-й неделе. Через два квартала планка пересчитывается по замеренному приросту вертикали. Вертикаль четыре недели подряд получает меньше своей планки — вопрос идёт в совет.

Откуда это

  • Практика рынка Три ступени — общий лимит, ранжирование, совет для рычагов — видны у Авито, iFood и банков Citi, NatWest, NAB. Минимум и максимум числа сообщений по продуктам: Газпромбанк. Бюджеты команд не перетекают: Uber. Рост объёма только с согласия первого лица: Duolingo (пересказ).
  • ЦИАН, открытые данные Звонок застройщику приносит {{rev_per_lead|тыс1}} тыс. рублей, размещение даёт {{rev_share_listing|%0}} выручки. Отсюда нужда в планках: без них вертикаль с дорогим контактом вытеснит остальные.
  • Предложение Три класса, нижняя планка на {{b1_floor_quarters|num0}} квартала, быстрая полоса с ответом за {{b1_fast_lane_days|num0}} день, право оспорить за {{b1_appeal_days|num0}} рабочих дней, вторая версия — оценка по модели ценности (Ц1, Ц2) в режиме тени с третьего квартала; для аренды и вторички ручные доли, пока k не измерено; Monzo — аналог: человека получает тот, чей прирост выше.
  • Допущение Лимит {{limit_push_day|num0}} в сутки и {{limit_week|num0}} в неделю, потолок подписок {{b1_sub_cap_day|num0}} в сутки, испытательный срок {{b1_trial_days|num0}} дней. Долей между вертикалями не публикует никто.
