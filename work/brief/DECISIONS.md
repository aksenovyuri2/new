# Решения по замечаниям панели, круг 1

Средние оценки круга 1: практик CRM 3,2; CPO 3,0; директор «Первичного рынка» 2,8; финансовый директор 2,7; скептик по измерениям 2,5. Средняя 2,8.

## Блокеры и что сделано
| Критик | Блокер | Решение |
|---|---|---|
| CPO | Мандат переписывает цели директоров | Принято. 90 дней цели не меняем, мандат узкий (лимит, журнал, контроль), письмо CPO на 3-й неделе; новая метрика добавляется к охвату (записка п.6, Г1) |
| CPO | Нет дельты к имеющемуся CRM ЦИАН | Принято. Таблица «есть / нет / даёт платформа» (п.3, А2); a считаем сверх +16% |
| CPO | 90 дней нереалистичны, нет затрат | Принято. Недели 1–3 интервью и карта; одна вертикаль к 3 месяцам; стоимость 60–100 млн (п.2, Д2, Э2) |
| CFO | Нет стоимости и окупаемости | Принято. Безубыточность a 0,74–1,23% при k 0 (Э2) |
| CFO | Сценарии на цели, а не на прогнозе | Принято. Пересчёт на 26,2 млрд; a снижен до 0,5 / 1,5 / 4% (Э2) |
| CFO | Деньги за 6 месяцев не доказать | Принято. Платные звонки — с 12 месяца; таблица мощности (п.10, В2) |
| Измерение | Контроль меряет «всё против ничего», не платформу | Принято. Слой 1 — тест переноса вертикали 20/80 как эффект платформы; список контроля у всех отправщиков с 4-й недели (В2) |
| Измерение | Мощность и цели 6 месяцев не выводятся | Принято. Пересчёт для 3–5 млн достижимых; цели 3 мес — только процесс (п.10, Д2) |
| Измерение | «Добавленное действие» не определено | Принято. Человек, сравнение по назначению, 28+ дней, серверный журнал, знаменатель — все назначенные (В1) |
| CRM | v1 противоречит себе (формула) | Принято. v1 — шлюз-запрет без оценки; формула — v2 (п.5, Б2) |

| CRM | Доставка и согласия не влезают в 90 дней | Принято. Прогрев почты и юристы с 1-й недели; одна вертикаль к 3 месяцам (Д1, Д2) |
| Вертикаль | Цена контроля занижена, нет защиты лидов | Принято частично. Цена 12–59 млн по лидам; потери учитываются в плане вертикали. Порог 0,5% по лидам отклонён: его не видно замером; вместо — целевые действия вертикали с допуском 2% за квартал (п.8, В3) |
| Вертикаль | Планки без чисел, потолки лишние | Принято. Нижняя планка = текущая отправка на человека два квартала; без потолков в v1 (Б4) |
| Вертикаль | Нет апелляции и быстрой полосы | Принято. Быстрая полоса 1 день, апелляция 5 дней, место в совете (п.6, Г2) |

## Отклонено
- Право вертикали уйти на нулевую версию: ломает общий лимит.
- 1% случайных решений для обучения на платных звонках: звонков мало; обучение во второй версии на ближних действиях.
- Делить бюджет отписок пропорционально деньгам вертикали: закрепит перекос в пользу новостроек; делим по текущей доле отправок, потом по замеру.

## Принято из замечаний
- «Хаос» → «нет координации и общего счёта».
- «Страховка 92%» переписана; доля возвратов через пуш и письма вынесена в пробелы.
- Чувствительные темы на экране блокировки.
- Вакансия CRM-аналитики помечена «проверить»; оргструктура по рынкам вместо «вертикали Аудитория» 2023 года.
- Цену отписки в рублях не приводим (разброс в 40 раз), это пробел.
- План вертикалей по лидам в первый год остаётся валовым; прирост показывается рядом.
