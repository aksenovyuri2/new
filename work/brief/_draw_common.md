## Устройство раздела
Файл начинается строкой `<!-- tab: ИМЯ_ВКЛАДКИ -->`. Каждая схема — `<article class="scheme" id="s-КОД">` с:
- `<header>`: `<p class="code">` (код, «★ ядро» для схем ядра, вопрос кейса), `<h2>` — заголовок-вывод, `<p class="sub">` — 1–2 предложения;
- `<figure>` с `<div class="draw"><svg viewBox="0 0 960 H" role="img" aria-label="...">…</svg></div>` и `<figcaption>`;
- полоса «Рынок»:
```html
<div class="market"><h3>Рынок</h3><ul>
  <li><span class="who">Авито</span> · балансировщик: из 400+ кампаний в день человеку проходят лучшие в пределах лимита · 01.2025 · <span class="src">П</span> · <span class="fit hi">применимо: площадка с вертикалями, РФ</span> · <a href="URL" rel="noopener">источник</a></li>
</ul></div>
```
  3–5 строк. Класс fit: hi (высокая применимость), mid, lo. Ссылку бери из unit_links.py. Тип: П — сама компания, В — вендор, Т — третья сторона.
- `<div class="answer"><h3>Ответ на вопрос кейса</h3><ul>…</ul></div>` — 3–5 пунктов;
- где есть выбор — таблица компромиссов: `<div class="tablewrap"><table class="tradeoff"><thead><tr><th>Решение</th><th>Альтернатива</th><th>Цена выбора</th><th>Кто так делал</th></tr></thead><tbody>…</tbody></table></div>`;
- `<div class="basis"><h3>Откуда это</h3><ul>` с метками `<span class="mark task">Из задания</span>`, `mark cian` («ЦИАН, открытые данные»), `mark market` («Практика рынка»), `mark assume` («Допущение»), `mark prop` («Предложение»).

## Числа
Каждое число на схеме пишется кодом `{{код|формат}}` (форматы: `%1` — проценты с 1 знаком, `num0`, `num2`, `тыс1`, `млн0`). Существующие коды — в /home/user/new/work/numbers.json. Новые коды добавляй ТОЛЬКО в свой файл /home/user/new/work/numbers_БЛОК.json (имя в задании) — список объектов {"code", "value", "unit", "origin" ("задание"|"ЦИАН"|"рынок"|"оценка"|"допущение"), "note", "src" (номер абзаца или карточки)}. Коды в нижнем регистре латиницей с префиксом блока. Числа рынка в полосе «Рынок» можно писать прямо текстом.

## Рисунок
