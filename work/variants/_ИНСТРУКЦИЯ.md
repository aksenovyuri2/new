# Инструкция: отбор вариантов из пакета исследования

Ты разбираешь часть большого исследования о том, как крупные компании управляют сообщениями пользователям (CRM). Пакет — это текст отчёта, где у каждого абзаца и каждой строки таблицы есть номер в квадратных скобках, например [R2-0081].

Задача: пройти пакет по порядку, абзац за абзацем, и выписать ВСЕ варианты: что делает каждая названная компания, вендор, закон, научная работа. Ничего не пропускать и ничего не добавлять от себя.

## Формат записи

```
### Название компании или источника
- суть: что именно делает или утверждает, до 40 слов, только то, что написано в абзацах
- числа: числа, формулы и пороги дословно как в тексте, через точку с запятой; если их нет, слово «нет»
- абзацы: R2-0081, R3-0123
- вид: 2–4 слова, тип решения (например: общий лимит, формула приоритета, контрольная группа, совет по спорам)
```

## Правила

1. Одна запись — одна компания и один механизм. Если компания делает две разные вещи, это две записи с одинаковым заголовком.
2. Если в одном абзаце названо несколько компаний, для каждой своя запись.
3. Компании ищи в самом тексте, а не только в ссылках. Примеры: «Авито: балансировщик…», «у Monzo…», строка таблицы с названием в первой ячейке.
4. Собственные выводы авторов отчёта (варианты решений, сводные формулы, оценка силы базы, пробелы, «публичных данных нет») записывай под заголовком `### СИНТЕЗ ОТЧЁТА`. Каждый вариант решения — отдельная запись.
5. Числа не округляй, не переводи и не пересчитывай. Каждое число из полей «суть» и «числа» должно быть в указанных абзацах.
6. В поле «абзацы» только номера из пакета.
7. В конце файла раздел `## Пропущено`: номера абзацев, которые не вошли ни в одну запись, и причина одним-двумя словами (заголовок, служебное, список ссылок без содержания). Каждый номер пакета должен быть либо в записи, либо в «Пропущено».
8. Пиши по-русски. Никаких вступлений и итогов в файле: только записи и раздел «Пропущено».
