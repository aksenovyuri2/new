  • Центр данных — один поток событий с единым справочником и реестр согласий. Карточка человека собирается из потока, а не из кабинетов команд. У Авито это {{in_avito_events|млн0}} млн событий в минуту из {{in_avito_sources|num0}}+ источников.
  • Долю опознанных растим через Яндекс ID, Сбер ID, VK ID и T-ID, а не через отпечаток браузера. Вход не отдаём одному банку: Сбер ID усиливает Домклик.
  • Внешние данные идут без выгрузки ПД. ЦБ и ДОМ.РФ дают поводы для сообщений и сверку лотов; партнёры — только обезличенный ID или чистая комната.
  • Право — граница. Согласие на ПД отдельным документом, cookie — ПД, реклама только с согласия. Любой новый источник проходит три шага: согласие и цель, ПД внутри, эффект в рублях.
  • Жизненные события и добычу данных включаем, когда есть контрольная группа и модели прироста (схема И2). Событие считаем догадкой с точностью {{in_life_lo|num0}}–{{in_life_hi|num0}}%, а не фактом, и в тексте не называем.
